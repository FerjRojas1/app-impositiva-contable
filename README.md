# AppEstudioContable

Sistema web de gestión impositiva desarrollado como **Práctica Profesional Supervisada (PPS)** para la gestión y procesamiento de información fiscal de contribuyentes Responsables Inscriptos.

El sistema permite importar información de **ventas y compras** a partir de archivos Excel exportados desde **ARCA**, procesar y clasificar los datos y utilizar esa información para la determinación de diferentes obligaciones impositivas.

## 🎯 Objetivo

Centralizar y automatizar parte del procesamiento de información contable e impositiva, reduciendo tareas manuales y facilitando la consulta de la información fiscal de cada contribuyente.

## 🚀 Funcionalidades

### Gestión de clientes

* Alta, modificación y consulta de clientes.
* Administración de la información asociada a cada contribuyente.

### Importación de información

* Importación de archivos Excel de ventas.
* Importación de archivos Excel de compras.
* Procesamiento y clasificación de la información importada.

### Cálculos y reportes impositivos

* Determinación de **IVA**.
* Cálculo de **Ingresos Brutos mensual**.
* Cálculo de **Ingresos Brutos anual**.
* Resumen de información para **Ganancias**.

## 🛠️ Tecnologías

* **Backend:** ASP.NET / C#
* **Frontend:** Bootstrap / JavaScript
* **Base de datos:** SQL Server
* **ORM:** Entity Framework
* **Control de versiones:** Git / GitHub

## 🏗️ Arquitectura

La aplicación sigue una arquitectura basada en **ASP.NET MVC**, separando las responsabilidades principales entre:

* **Models:** representación de entidades y datos.
* **Views:** interfaces de usuario.
* **Controllers:** lógica de aplicación y comunicación entre las diferentes capas.
* **Database:** persistencia de información mediante SQL Server.
